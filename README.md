# Tetris Modular Practice Engine

This is a modular practice engine for the game Tetris. It allows users to customize their gameplay experience by modifying various settings and features. This is essentially a python for of Four-tris. Any feedback is welcome

## Installation

1. Clone this repository:
   ```sh
   git clone https://github.com/yourusername/tetris-practice-engine.git
   ```

2. Install the required dependencies:
   ```sh
   pip install -r requirements.txt
   ```

3. Run the game:
   ```sh
   python main.py
   ```

## Features

- **Customizable Settings**: Users can adjust various settings such as lock delay, max lock resets, and infinite hold.
- **Piece Classification**: The engine uses HSV color classification to classify cells in the screenshot.
- **Screenshot Import**: Users can import a screenshot from their device to play Tetris with the captured image.
